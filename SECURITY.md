# Security policy

This repository is a public portfolio demo. The default in-memory mode is not
production persistence, and the demo credentials/data must not be reused for
real tenants.

If you find a security issue, do not open a public issue with exploit details.
Contact the repository owner through the private contact options on the owner's
GitHub profile and include the affected commit and a minimal reproduction.
There is no guarantee of a production response SLA.
